## Execution order and exact commands
Run from repository root with a compatible Python environment. The commands below never perform search.

```bash
python -m pip install -r requirements-repro.txt
python -B candidate/publication/validate_package.py
python -I -B reproduce_best.py --verify --out replay_new
```

`replay_new` must not exist. The runner checks packaged source/state/lock hashes, loads trusted local state and checks one predeclared episode at each of five budgets. It does not load query truth. Its output contains probabilities, predictions and verification metadata. Expected prediction arrays are also protected by the publication manifest.

### Rebuild publication evidence
The supplied archive already includes verification outputs. Recreate tables and all 32 figure sets without any model fitting:

```bash
python -B candidate/publication/build_publication.py
```

This reads saved evaluation truth **only for evaluation**, recomputes all 4,000 confusion/F1 records, checks all 1,000 support/query exclusions, computes statistics, and regenerates figures. It overwrites only Phase-2 generated tables/figures/reports, never original experiments. Timing/environment metadata and PDF creation metadata may change; numerical evidence is reproducible, but rebuilt publication bytes are not promised identical. Revalidate the original distribution before rebuilding; regenerated bytes naturally invalidate its old hash seal. The maintainer-only `audit_and_seal.py` can issue a new local seal after reviewing changes; a new seal is not a substitute for validating the received archive.

For fresh profiling, first rename `candidate/reproducibility/verification/` to a unique preserved directory, then run:

```bash
python -B candidate/publication/verify_evidence.py
python -B candidate/publication/build_publication.py
```

The profiling script refuses to overwrite existing verification results. It runs exactly ten fixed-reference calls, records local RF importance and timings, and receives no query truth. No source prior is refitted.

### Optional source-state rebuild (expensive; not run in publication phase)

```bash
python -B candidate/publication/verify_source.py --out source_replay_new
```

Requires the original hashed `data/preprocessed/preprocessed_data.pkl`. It invokes the unchanged source-fitting implementation, compares eight state arrays exactly, and performs no optimization or scoring. The historical data container includes target truth, which is removed before fitting. Do not run historical optimization drivers. The earlier full fresh-source/1,000-episode replay is preserved at `candidate/autonomous_runs/20260909_1727/clean_replay/verification.json`; that completed experiment was not restarted.

### User-supplied support inference
Create an NPZ with integer `indices`, class `labels` (1–4), integer scalar `budget` in {5,25,50,100,200}, and optional non-overlapping integer `query` indices. Supply exactly budget labels/class and preserve bound-pool indexing.

```bash
python -I -B reproduce_best.py --support support.npz --out predictions_new
```

The package is not valid for arbitrary reordered or unseen target pools. Hash checking does not make untrusted pickle deserialization safe.

- [SHA256SUMS.json](../../SHA256SUMS.json): publication distribution file hashes; excludes itself to avoid self-reference.
- [Freeze baseline](../reproducibility/freeze_before.json): pre-publication protected code, artifacts and original evidence hashes.

- [Command manifest](../reproducibility/command_manifest.json): commands executed, intended replay order and failure recovery.
- [Directory hashes](../reproducibility/directory_hashes.json): SHA256 of sorted `relative/path + NUL + file_digest + LF` entries per directory, over the documented seal scope, excluding circular seal files.
- [Artifact manifest](../reproducibility/artifact_manifest.json): path, size, role and digest inventory.
- [Validation](../reproducibility/final_validation.json): freeze, figure, table and link checks.

No competitor code, results, figures or forensic workflows are consumed by publication scripts or included in the allowlisted submission archive. Original research paths are retained outside that export where needed for provenance. The export contains inference state, saved evaluation evidence, preprocessed data and publication assets; it supports inference and numerical publication replay without raw parquet files. Raw-data-to-preprocessed rebuilding still requires organizer data and the historical notebook environment; it was not repeated or certified here. Redistribution permission must be checked before public upload of data-bearing archives.
